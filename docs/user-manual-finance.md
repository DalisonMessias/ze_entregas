# Manual do Usuário – Financeiro Unificado

## Zebank (Entregadores)
- Acessar: Menu → `Zebank`
- Seções:
  - Saldo e Extrato Pessoal
  - Transferir (P2P)
  - Guardar/Resgatar (Poupança)
  - Cartões Virtuais (criar, bloquear, ajustar limite)
- Observações:
  - Algumas funcionalidades avançadas exigem perfil Parceiro.

## ZéPay (Lojistas)
- Acessar: Menu → `ZéPay Corporativo`
- Tabs:
  - Visão Geral (saldo corporativo, código da loja)
  - Extrato (movimentações detalhadas da loja)
  - Maquininha (apenas Super Lojistas)
- Recarga de saldo:
  - Gere cobrança PIX em Carteira/Extrato (StoreWallet/FinancialPanel)

## Links Antigos
- `store_finance_panel` redireciona automaticamente para `ZéPay Corporativo`.

## Permissões
- Zebank: exclusivo para Entregadores
- ZéPay: exclusivo para Lojistas; recursos avançados para Super Lojistas

## Suporte
- Em caso de erro de acesso, verifique seu papel em Perfil ou contate o suporte.
